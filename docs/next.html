Next week: November 11, 2026

Scheduled. The next issue goes out November 11, 2026. The weekly cadence is simple: one topic, seven days, every week.

Write it in public

  1. Create or edit the stub file: posts/2026-11-11-new-topic.md (if it is missing, run python3 build.py next).
  2. Give it a real title: and summary:, then replace the TODO with the issue itself.
  3. Preview at home: python3 build.py build && python3 build.py serve.
  4. When the words are ready for readers, remove the draft: yes line from the front matter — that is the publish switch.
  5. Rebuild and commit both folders together: python3 build.py build, then commit posts/ and docs/ in one commit.

While a file is marked draft: yes, it stays on your machine: it is not built, not in the archive, and not in the RSS feed. Scheduling is public; drafts are private.
